# SyncWatch v0.1

아무 영상 탭 두 개를 하나의 타임라인으로 묶는다. 본편 + 리액션 동시시청용.

## 설치 (임시 부가기능)

1. `syncwatch.zip` 을 아무 데나 저장 (예: `~/syncwatch-ext/`)
2. Firefox → `about:debugging#/runtime/this-firefox`
3. **"임시 부가 기능 로드"** → zip 파일 선택
   (압축을 풀었다면 그 폴더의 `manifest.json` 선택)

⚠️ 임시 설치라 **Firefox를 재시작하면 사라진다.** 매번 다시 로드하면 된다.
영구 설치는 서명이 필요하다 (AMO 자체 배포 서명).

## 쓰는 법

1. 본편(넷플릭스 등)과 리액션(유튜브 등)을 각각 탭에서 **한 번 재생**한다.
   재생을 해야 확장이 영상을 인식한다.
2. 툴바의 SyncWatch 아이콘 클릭
3. 목록에서 한 탭에 **본편**, 다른 탭에 **반응** 지정
4. **묶기** 클릭 — 지금 두 위치의 차이가 오프셋으로 잡힌다
5. 안 맞으면 `−0.5s` / `+0.5s` 로 밀면서 맞춘다. **한 번 맞추면 자동 저장된다**

## 단축키

| 키 | 동작 |
|---|---|
| `Alt+Shift+S` | 동시 재생 / 정지 |
| `Alt+Shift+,` | 리액션 0.5초 당기기 |
| `Alt+Shift+.` | 리액션 0.5초 밀기 |

## 오프셋 공유

**내보내기** → 나온 JSON을 남에게 주면, 그쪽은 **불러오기** 한 번으로 정확히 같은 싱크가 된다.

```json
{
  "main":     { "host": "www.netflix.com", "id": "81234567" },
  "reaction": { "host": "www.youtube.com", "id": "dQw4w9WgXcQ" },
  "offsetMs": -142300
}
```

## 구조

| 파일 | 역할 |
|---|---|
| `content.js` | 페이지마다 실행. 영상을 찾고 어댑터로 제어 |
| `background.js` | 동기화 엔진. `reaction.time == main.time + offset` 만 지킨다 |
| `popup.js` | UI |

**어댑터는 사이트를 안 가린다.** 기본 어댑터가 `<video>` 엘리먼트를 직접 다뤄서
티빙·웨이브·라프텔·로컬 파일 등 대부분이 코드 추가 없이 그냥 된다.
특수 어댑터는 기본형이 깨지는 곳에만 만든다 — 현재는 넷플릭스 하나
(내부 플레이어 API로 seek해야 버퍼가 안 꼬임).

## 드리프트 보정

| 어긋남 | 대응 |
|---|---|
| < 0.15초 | 아무것도 안 함 (사람이 못 느낌) |
| < 2초 | 재생속도 ±5%로 소리 없이 스르륵 |
| ≥ 2초 | 강제 seek |

## 알려진 한계

- **DRM 사이트는 다른 페이지에 임베드 불가.** 그래서 배치는 PiP로 푼다
- PiP는 사용자 제스처를 요구해서 팝업 버튼으로 안 될 수 있다. 그땐 영상 위 우클릭 2번 → PiP
- 넷플릭스 내부 API는 아직 실제 검증 전. 안 되면 기본 어댑터로 자동 폴백된다
